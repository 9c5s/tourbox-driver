# ADR-0005: 単発の振動は対象外にする

- 状態: 承認 (2026-09-23、Discord で承認)
- 日付: 2026-09-23

## 文脈

ユーザーは、DAW から送った MIDI (Note など) のタイミングで TourBox を振動させる使い方 (メトロノームやキュー) を希望した。
公開されている Linux 向け非公式ドライバの解析では、ハプティクスは「回転操作の刻みに対する手応え」を軸ごとに設定する 94 バイトのメッセージだけで、任意のタイミングで振動させるコマンドは見つかっていなかった。
公式コンソールは TourBox 固有のクラスが暗号化と難読化で保護されており、静的解析はしない方針にした。
2026-09-23 に、公式コンソール 5.11.3 と実機の USB 通信を USBPcap で記録し、触覚の強さ、回転速度、作動スイッチの操作中にホストが送ったメッセージを解析した。
30 件すべてが 94 バイトの設定メッセージで、他の種類はなかった。
コンソールの UI にも振動をテストする項目はなかった。

## 決定

単発の振動は対象外にする。
MIDI 入力によるハプティクス制御は、軸ごと (と修飾との組み合わせごと) の強度と速度の切り替えに限定する。

## 検討した選択肢

- 公式コンソールを静的解析して隠しコマンドを探す。保護の回避になるため採らない。
- 回転の手応えの設定を短時間だけ切り替えて振動の代わりにする。回転していないと振動しないため、代替にならない。

## 結果

- 実機キャプチャは `docs/protocol/haptic-captures.md` に保存し、94 バイトメッセージの組み立てのテストの期待値に使う。
- キャプチャから、公式の「作動 OFF」は速度ビットが一部残ること、軸単位の変更が全組み合わせには及ばないことも分かった。本ドライバの master OFF は速度も含めて全値 0 を送り、公式と同一ではない (設計書 2.5 節)。
